# Review, completeness, provenance, and rights

## What is transferred

Only language-specific text packages for ja, fil, vi, zh-CN, uz, and hi from the formerly public Hadith-related materials are copied. Each cataloged source file is copied from its pinned Git revision. A SHA-256 mismatch prevents a clean audit claim. Additional public but uncataloged files are placed in a separate revision folder and reported.

All reading and source envelope bytes live under languages/<code>/books/essential/editions/. The runtime index and local search utility have no dependence on any other source repository.

## What has NOT been independently verified

- That every historical record is a prophetic Hadith rather than a saying, Quran citation, commentary or authored lesson.
- That a passage has all Arabic source text, complete isnad, precise canonical version matching, edition and original book numbering.
- That every translation was authored by a human or by a known AI model, or independently checked by a scholarly reviewer.
- That the six-language collections comprise every available book or narration.
- That all copyrighted translations are approved for every form of redistribution.

## Publication restrictions

The migrated files were already publicly available in the source repository. That fact alone does not constitute a new license. The repository remains a research corpus with preserved source conditions. Any new PDF-based extraction, full-book OCR or unapproved translation must remain outside the published bank until rights, separate Pro QC and source-fidelity checks are recorded.

## Import audit

See reports/IMPORT-STATUS.json for each file's local path, SHA256, original pinned revision or uncataloged source revision, bytes, integrity exceptions and exact scope. The six language catalogs distinguish catalog-indexed packages from readings without a complete source envelope. The metadata index source records are not equivalent to unique narrations.
