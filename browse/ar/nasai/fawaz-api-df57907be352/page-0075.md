<p dir="rtl">ابو سعید خدری رضی الله عنہ کہتے ہیں کہ ایک شخص جمعہ کے دن مسجد میں داخل ہوا، رسول اللہ صلی اللہ علیہ وسلم جمعہ کا خطبہ دے رہے تھے، تو آپ نے فرمایا: ”تم دو رکعتیں پڑھو“، پھر وہ شخص دوسرے جمعہ کو بھی آیا اور نبی اکرم صلی اللہ علیہ وسلم خطبہ دے رہے تھے، تو آپ نے فرمایا: ”تم دو رکعتیں پڑھو“، پھر وہ تیسرے جمعہ کو ( بھی ) آیا، آپ نے فرمایا: ”دو رکعتیں پڑھو“، پھر آپ نے لوگوں سے فرمایا: ”صدقہ دو“، تو لوگوں نے صدقہ دیا، تو آپ نے اس شخص کو دو کپڑے دئیے، پھر آپ نے پھر فرمایا: ”لوگو صدقہ دو“، تو اس شخص نے اپنے ان دونوں کپڑوں میں سے ایک کو آپ کے سامنے ڈال دیا، رسول اللہ صلی اللہ علیہ وسلم نے فرمایا: کیا تم لوگوں نے اس شخص کو نہیں دیکھا؟ یہ خستہ حالت میں مسجد میں آیا، میں نے امید کی کہ تم لوگ اسے دیکھ کر اس کی خستہ حالی کو تاڑ لو گے اور اسے صدقہ دو گے، لیکن تم لوگوں نے ایسا نہیں کیا، تو مجھ ہی کو کہنا پڑا کہ تم صدقہ دو، تو تم لوگوں نے صدقہ دیا تو میں نے اسے دو کپڑے دئیے، پھر لوگوں سے کہا: ”صدقہ دو“، تو اس نے ان کپڑوں میں سے ( جو ہم نے اسے دیے تھے ) ایک ( ہمارے آگے ) ڈال دیا، ( ارے بیوقوف ) تم اپنا کپڑا لے لو، آپ نے اسے ڈانٹا ۱؎۔</p>
